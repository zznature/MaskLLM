## 🎯 为什么 Iter 1235 更安全？

### **1. Reg Loss 更低**

```
Iter 1235: 8692.5  ← 健康
Iter 1310: 9032.4  ← 危险边缘

差异: 339.9 (3.9% 增长)

影响:
  Reg loss 高 → Mask 正则化压力大
           → 梯度更大
           → 更容易 NaN

结论: Iter 1235 的 Reg loss 更可控
```

### **2. Temperature 更高**

```
Iter 1235: 2.458  ← 更"soft"
Iter 1310: 2.364  ← 更"hard"

影响:
  Temperature 低 → Gumbel-Softmax 更确定
                → exp() 值域更极端
                → 数值不稳定风险高

结论: Iter 1235 的 Temperature 提供更大安全余量
```

### **3. Max Prob 不那么极端**

```
Iter 1235: 0.609  ← 适中
Iter 1310: 0.637  ← 更极端

影响:
  Max prob 高 → Mask 选择更确定
             → 梯度对小扰动更敏感
             → FP32 下更易 NaN

结论: Iter 1235 更保守
```

### **4. Scale Multiplier 更低**

```
Iter 1235: 173.4  ← 较低
Iter 1310: 180.9  ← 较高

影响:
  Scale mult 高 → Mask logits 的缩放更大
               → 数值范围更广
               → 累积误差更大

结论: Iter 1235 数值范围更安全
```

## 💡 经验总结

### **Checkpoint 选择的重要性**

```
错误思路:
  从最新 checkpoint 恢复 (iter 1310)
  → 权重已经不稳定
  → FP32 也救不回来

正确思路:
  从最早的稳定 checkpoint 恢复 (iter 1235)
  → 权重健康
  → FP32 + 保守参数
  → 有望完成训练

关键教训:
  "最新" ≠ "最好"
  健康的起点 > 节省计算
```

### **Reg Loss 的警示作用**

```
Reg loss 是训练健康度的关键指标:

健康: < 8500
  → 安全区

警戒: 8500-9000
  → 需要密切监控

危险: > 9000
  → 随时可能 NaN

临界: > 9500
  → 立即停止训练
```
